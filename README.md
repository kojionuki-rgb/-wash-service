# RideLog Pilot & 洗車サービス

タクシー業務で使用する個人向けWebツールをまとめたリポジトリです。

現在は主に、乗務記録を扱う **RideLog Pilot** と、洗車受付・進捗管理を行う **洗車サービス** を収録しています。

---

## 🚕 RideLog Pilot v1.6

**Release: 2026-09-20**

タクシー乗務中の記録を、できるだけ少ない操作で残すためのWebアプリです。

### v1.6 Improvements

- ホーム内訳を「Uber / 手上げ / その他」に変更
- 各内訳に合計金額と合計回数を表示
- 「駅」を「駅、乗り場」に変更
  - 既存の「駅」データも緑表示を維持
- 本日の乗車記録で未入力項目を赤枠表示
- 待機中は「降車」、乗車中は「乗車」を一回り縮小し、次に押すボタンを視覚的に強調
- v1.5の個人タクシー運転日報機能を継続

### 主なファイル

`RideLog_Pilot_v1.6.html`

## 🧽 洗車サービス v6.6

**Stable: 2026-10-01**

タクシーの洗車依頼を受付し、作業状況・支払い状況まで管理するWebアプリです。  
受付データはSupabaseを利用してクラウド保存します。

### 主な機能

- 洗車受付の登録
- 受付日・次回出庫時間の管理
- 無線番号による車両検索
- 無線番号マスターとの連携
  - 班
  - 乗務員
  - 基本出庫時間
- 複数の基本出庫時間がある場合の時間選択
- 受付リストの検索・状態絞り込み
- 受付リストからのデータ削除
- 全角数字の無線番号をIME確定後に半角へ自動変換
- Supabaseによるクラウド保存

### 状態表示

| 状態 | 色 |
| --- | --- |
| 受付 | 🟢 緑 |
| 洗車完了 | 🟣 紫 |
| 支払い済み | 🔵 青 |
| 未収 | 🟡 黄 |
| キャンセル | 🩷 ピンク |

### v6.6 Changes

- 「洗車完了」を紫色に変更
- 「受付」の緑色との判別性を改善

### 最近の更新

- **v6.5** — 日本語IMEで全角数字入力時に発生していた二重入力を修正
- **v6.3** — 複数の基本出庫時間から選択する機能を改善
- **v6.2** — 受付リストから直接削除できる機能を追加
- **v6.1** — 「洗車完了」状態を追加
- **v6.0** — 無線番号マスター連携を追加

### 主なファイル

`wash_service_cloud_v6_6.html`

## 運用方針

実際のタクシー業務で使用しながら改善しています。

新機能を増やすことよりも、

**「迷わず押せる」「すぐ記録できる」「あとから確認できる」**

ことを優先します。

安定版は残し、不具合が発生した場合に以前のバージョンへ戻せるようにします。
